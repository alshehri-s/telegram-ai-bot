# 🤖 Telegram AI Bot

بوت تيليجرام ذكي يعتمد على الذكاء الاصطناعي للإجابة على الأسئلة التعليمية.

## 🚀 المميزات
- يستخدم واجهة **OpenAI API** لتوليد الإجابات.
- مدمج مع **FastAPI** لتسهيل الاستضافة على Render.
- يدعم الردود باللغة العربية.
- يمكن ربطه بقنوات تيليجرام ليرد تلقائيًا على الأسئلة.

## ⚙️ التشغيل المحلي
```bash
pip install -r requirements.txt
python main.py
